# NextRep

NextRep is a small strength-training calculator that turns your latest weight and reps into a recommended weight for your next session.

## Progression calculation

- At or above the maximum target reps: add the chosen weight increment.
- Within the target rep range: keep the current weight.
- Below the minimum target reps: subtract the chosen increment, without going below zero.

Choose either kg or lb for display. NextRep does not convert between units.

## Technologies

HTML, CSS, and JavaScript. No frameworks, backend, APIs, or external dependencies.

## Run locally

Download the project and open `index.html` in a web browser.
